INSTRUÇÕ PARA PDF
-----------------

Para gerar um PDF com essas prints:

1. Organize os arquivos na ordem desejada conforme a sequência acima.
2. Cada print screen já captura o estado visual da página no navegador.
3. Os prints rotulados como "-menu-aberto" já ilustram o estado aberto
   dos menus dropdown/abas respectivos.
4. Use qualquer ferramenta de concatenação de PDF (Preview no Mac,
   Adobe Acrobat, PDFtk, etc.) para unir as imagens em um único documento.
5. As imagens já vem com dimensões adequadas (aprox. 1.6MB cada, qualidade
   alta para apresentação).

O PDF resultante terá uma prints por página da arquitetura do site,
com destaque especial para os momentos em que os menus dropdown estão
expandidos, demonstrando a navegação interativa do protótipo.
